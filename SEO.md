# Поиск: как сайт находят в Google, Яндексе и соцсетях

## Что сделано в коде

- **Отдельный адрес у каждой страницы и языка** (раньше всё было после `#`, и поисковики видели одну страницу):
  - английский: `peltanera.com/`, `/c/bag`, `/p/ch-01`, `/about`, `/contact`, `/privacy`
  - русский: `peltanera.com/ru/…`, узбекский: `peltanera.com/uz/…`
  - старые ссылки с `#/…` (в том числе кнопка из Telegram-бота) сами переходят на новые адреса.
- **Готовая HTML-страница для каждого адреса** создаётся при сборке (`scripts/seo-pages.ts`): заголовок, описание, текст страницы, цена товара. Поисковики видят содержимое сразу, без JavaScript.
- **hreflang**: Google и Яндекс знают, что `/ru/…` и `/uz/…` — переводы той же страницы, и показывают нужный язык.
- **schema.org**: бренд (Organization, со всеми вариантами названия: «Pelta Nera», «Пелта Нера», «PeltaNera»…), товары с ценой (Product), «хлебные крошки», контакты.
- **Open Graph**: красивые превью ссылок в Telegram, Instagram, WhatsApp.
- **sitemap.xml** и **robots.txt** (создаются сами при каждой сборке, 45 адресов).
- Закрытые товары (Exclusive) в поиск не попадают.

Новый товар в `src/lib/products.ts` автоматически получает свои страницы на трёх языках и попадает в sitemap.

## Что нужно сделать вручную (один раз)

1. **Google Search Console** — ресурс `https://peltanera.com/` уже добавлен, метатег подтверждения в `index.html`.
   После `push.bat` (через 2 минуты): search.google.com/search-console → **Подтвердить** →
   «Файлы Sitemap» → `sitemap.xml` → Отправить.
2. **Яндекс Вебмастер** (важно для русскоязычного поиска): webmaster.yandex.ru → добавить `https://peltanera.com` →
   способ «Мета-тег» → прислать Claude строку `<meta name="yandex-verification" …>` → после публикации «Проверить» →
   «Индексирование → Файлы Sitemap» → `https://peltanera.com/sitemap.xml`.
3. **Bing Webmaster Tools**: bing.com/webmasters → «Импорт из Google Search Console» (одна кнопка).
4. **Google Бизнес-профиль** (карта и блок справа в поиске по «Pelta Nera»): business.google.com →
   тип «Интернет-магазин / бренд без адреса для посетителей», город Ташкент, сайт, телефон, фото изделий.
   Аналог в Яндексе — Яндекс Бизнес.
5. **Домен peltanera.uz**: в настройках регистратора переадресация лучше на `https://peltanera.com/uz/` (301).
6. **Ссылки на сайт** везде, где есть бренд: шапка Instagram, описание Telegram-канала, визитки, упаковка.
   Чем больше ссылок на `peltanera.com`, тем выше сайт в поиске.

Первые страницы появляются в Google обычно через 3–14 дней после отправки sitemap.
