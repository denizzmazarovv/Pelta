# Настройка Supabase для Pelta Nera

Регистрация на сайте работает так:

1. Клиент вводит имя, email, телефон и пароль.
2. На почту приходит **6-значный код**, клиент вводит его на сайте. Ссылки в письмах не используются.
3. При сбросе пароля тоже приходит код. После него клиент задаёт новый пароль.

Пройдите шаги по порядку. Названия пунктов даны как в панели Supabase (supabase.com/dashboard → ваш проект).

---

## Шаг 1. База данных (обязательно)

**SQL Editor → New query** → вставьте весь файл
`supabase/migrations/20261022120000_secure_profiles_and_auth.sql` → **Run**.

Что он делает:
- создаёт таблицу `profiles`;
- профиль создаётся сервером при регистрации, сайт сам вставлять строки не может;
- каждый клиент видит и меняет **только свой** профиль (RLS);
- менять можно только имя, телефон, интересы и согласие на рассылку. Email, id и даты изменить нельзя;
- удалять профили с сайта нельзя.

После этого откройте **Advisors → Security Advisor**: там не должно быть ошибок (Errors).

## Шаг 2. Ключи (обязательно)

**Project Settings → API Keys**. На сайт идут только:
- **Project URL**
- **anon / publishable key** (публичный, его можно показывать)

> ⚠️ **service_role / secret key никогда не вставляйте на сайт и в GitHub.** Он обходит всю защиту.

На GitHub: **Settings → Secrets and variables → Actions**. Проверьте, что там есть два секрета:
- `VITE_SUPABASE_URL` — Project URL
- `VITE_SUPABASE_ANON_KEY` — anon key

## Шаг 3. Настройки входа (обязательно)

**Authentication → Sign In / Providers → Email:**

| Настройка | Значение |
|---|---|
| Enable Email provider | ✅ |
| Confirm email | ✅ включено |
| Secure email change | ✅ включено |
| Secure password change | ✅ включено |
| Minimum password length | **8** |
| Password Requirements | **Letters and digits** |
| Email OTP Expiration | **600** (10 минут) |
| Email OTP Length | **6** |
| Prevent use of leaked passwords | ✅, если будет тариф Pro (на бесплатном недоступно) |

Там же: **Allow new users to sign up** включено, **Allow anonymous sign-ins** выключено. Другие провайдеры (Google, Apple и т.д.) оставьте выключенными, если не используете.

**Authentication → URL Configuration:**
- Site URL: `https://peltanera.com`
- Redirect URLs: `https://peltanera.com/**`

## Шаг 4. Свой почтовый сервер SMTP (обязательно для запуска)

Встроенная почта Supabase отправляет **всего 2 письма в час** на весь проект и только для тестов. Без своего SMTP клиенты просто не получат коды.

Бесплатные варианты:
- **Resend** (resend.com): 3 000 писем в месяц, до 100 в день;
- **Brevo** (brevo.com): 300 писем в день.

1. Зарегистрируйтесь и подтвердите домен `peltanera.com`: сервис покажет DNS-записи, их нужно добавить там, где куплен домен. Это нужно, чтобы письма не попадали в спам.
2. **Authentication → Emails → SMTP Settings** → Enable Custom SMTP. Вставьте данные из сервиса. Отправитель: `no-reply@peltanera.com`, имя: `Pelta Nera`.
3. **Authentication → Rate Limits**: «Rate limit for sending emails» поставьте около **30 в час**. Остальные лимиты оставьте по умолчанию: они защищают от перебора паролей и кодов.

## Шаг 5. Шаблоны писем с кодом (обязательно)

**Authentication → Emails → Templates.** В каждом шаблоне должен быть `{{ .Token }}`, это и есть код.

### Confirm signup
Тема: `Код подтверждения Pelta Nera: {{ .Token }}`
```html
<div style="font-family:Arial,sans-serif;max-width:480px;margin:auto;color:#111">
  <p style="font-size:22px;margin:0 0 24px">Pelta Nera</p>
  <p>Ваш код подтверждения email:</p>
  <p style="font-size:32px;letter-spacing:8px;font-family:monospace;margin:16px 0">{{ .Token }}</p>
  <p style="color:#666;font-size:13px">Код действует 10 минут. Если вы не регистрировались на peltanera.com — просто проигнорируйте это письмо.</p>
</div>
```

### Reset Password
Тема: `Сброс пароля Pelta Nera: {{ .Token }}`
```html
<div style="font-family:Arial,sans-serif;max-width:480px;margin:auto;color:#111">
  <p style="font-size:22px;margin:0 0 24px">Pelta Nera</p>
  <p>Код для сброса пароля:</p>
  <p style="font-size:32px;letter-spacing:8px;font-family:monospace;margin:16px 0">{{ .Token }}</p>
  <p style="color:#666;font-size:13px">Код действует 10 минут. Если вы не запрашивали сброс — ничего не делайте, ваш пароль останется прежним. Никому не сообщайте этот код.</p>
</div>
```

## Шаг 6. Защита от ботов (рекомендуется)

Без капчи бот может массово регистрировать фейковые email и тратить ваш лимит писем.

1. Cloudflare → **Turnstile** → Add widget. Домен: `peltanera.com`, режим: **Managed**. Это бесплатно.
2. Supabase → **Authentication → Attack Protection → Enable CAPTCHA protection** → провайдер Turnstile → вставьте **Secret Key**.
3. **Site Key** вставьте в `src/lib/config.ts`:
   ```ts
   export const TURNSTILE_SITE_KEY: string = '0x4AAAA...';
   ```
4. Отправьте изменения на GitHub.

> Включайте капчу в Supabase и на сайте **одновременно**, иначе вход перестанет работать.

## Что уже защищено в коде сайта

- **Подбор паролей и кодов.** Лимиты Supabase: не больше 30 попыток входа или проверки кода за 5 минут с одного IP. Код живёт 10 минут и работает один раз.
- **Проверка, зарегистрирован ли email.** При сбросе пароля сайт всегда отвечает одинаково, есть аккаунт или нет. При входе ошибка всегда одна: «Неверный email или пароль».
- **Сброс пароля.** Работает только по коду из письма. Чужую ссылку перехватить нельзя, ссылок нет.
- **Смена пароля в аккаунте.** Нужен текущий пароль, поэтому с чужого незакрытого компьютера пароль не сменить.
- **Выход на всех устройствах.** Есть кнопка в аккаунте, если клиент подозревает взлом.
- **Чужие данные.** RLS в базе: даже с ключом сайта нельзя прочитать чужой профиль.
- **Мусор и вредные данные.** Длина имени, формат телефона и список интересов проверяются в самой базе.
- **Слабые пароли.** Минимум 8 символов, буквы и цифры, проверка на сайте и в Supabase.
- **Повторная отправка кода.** Не чаще раза в 60 секунд.

## Бесплатный тариф Supabase

- **50 000 активных пользователей в месяц.** Считаются те, кто входил в этом месяце, а не все зарегистрированные.
- **500 МБ базы.** Профиль занимает меньше 1 КБ, так что это сотни тысяч клиентов.
- **5 ГБ трафика.**
- ⚠️ **Проект засыпает, если неделю к нему не было запросов.** Тогда вход и регистрация не работают, пока не нажмёте «Restore» в панели. Пока на сайт заходят и логинятся клиенты, это не грозит. Тариф Pro ($25/мес) снимает это ограничение.
- Защита от утёкших паролей и настройка времени сессий есть только в Pro.

Удаление аккаунта клиенты запрашивают письмом. Удалить можно в **Authentication → Users → … → Delete user**, профиль удалится автоматически.
